# 비교 기준은 기존 Full-FEA 보정법까지 포함한다

2026-10-27. 저자가 지정한 「JEET 캡처와 독립 검토 이어가기」와 최신 원고 커밋 `73a1e2aff57bc5e2570dfb0c77a78c4452f027bb`를 확인했다. 원고는 이번 연구에서 읽기 전용이다.

## 기존 방법의 위치

JEET는 MS-FEA 기반 Hybrid의 한계를 희소 Full-FEA로 보정하는 방법을 이미 제안했다. 따라서 새로운 대리모델은 무보정 Hybrid와의 비교에 더해 **기존 AF 보정법보다 어떤 조건에서 정확도·표본 효율·적용 범위를 개선하는지**를 보여야 한다.

현재 원고의 기준은 평균제곱장 Hybrid다. Ref MS 위상 128개와 슬롯 표본 600개의 scalar |B|를 사용하며, skin-excess 항을 별도로 포함한다. 보정과 적용에 같은 평가식을 쓴다. 예전 표본선/캡 커널, GetDP 근접손, 상용 Hybrid에 같은 AF 계수를 곱하지 않는다.

보정 구조는 `AF(I,beta,omega) = f(omega) * kappa(I,beta)^p(omega)`다. 앵커 속도에서 전류·위상 표면을 적합하고 다른 속도의 수준과 퍼짐을 조정한다. RBF는 `r^2 log(r+1e-12)`, 정규화 항 `1e-6`, affine tail과 side constraint 없음이다. `f,p`는 속도에 대한 이차식이며, 구현·정규화·표본 마스크까지 고정된 파일을 기준으로 한다.

Ref는 16kRPM 앵커 24점과 낮은 속도 12점으로 36개 자체 Full-FEA를 사용한다. SC는 앵커 24점과 8kRPM 3점으로 27개 자체 Full-FEA를 사용하며 2/4kRPM에서는 도너 예측을 전달받는다. 전달 예측은 새 독립 Full-FEA 정답으로 세지 않는다.

## 최신 원고가 보고하는 서로 다른 평가 집합

| 집합 | Ref | SC | 해석 |
|---|---:|---:|---|
| loaded 전체 96점/기계 | 0.66% | 0.91% | 보정점을 포함한 full-grid wMAE |
| 자체 보정점 제외 | 60점, 2.38% | 69점, 2.76% | 2/4/8kRPM; 도너 의존성과 자체 제외를 구분 |
| HalfSC 고정 AF 전달 | 32점, 3.15% | — | 사전에 정한 격자, 추가 적합 없음 |

새 감사에서는 저장된 계수를 다시 적합하지 않고 scalar 예측과 평균제곱장 분모를 재계산한다. 원시 A/B의 생성·메시·물리 정확도 검증과는 구분한다. 정확한 출처와 재현값은 `baseline_audit/`를 참조한다. 현재 JEET-repro main의 옛 패키지를 최신 원고 성능으로 잘못 인용하지 않는다.

## 새 연구의 비교 순서

1. **B0 무보정 Hybrid.** 실제 제조 치수와 같은 운전점에서 평가한다. 평가식별 성적을 구분한다.
2. **B-AF 기존 JEET Full-FEA 보정법.** 이상 상사 가족에서 고정 모델을 재현한다. 비상사 형상에 적용할 때에는 제로샷 전달과 동일 예산 재앵커를 구분하고 지원 범위 밖을 명시한다.
3. **B1 제조 치수 잔차 모델.** 공극·절연·턴수·실제 도체 규격을 추가해 손실 잔차를 학습한다. `Full/Hybrid` 보정과 `Full/(AF*Hybrid)` 추가 보정은 다른 실험이다. 후자는 기존 AF가 유효하게 정의된 경우에만 사용한다.
4. **B2 출처를 구분한 다중 소스 학습.** 같은 목표 솔버의 독립 학습과 비교해 다른 솔버 자료를 추가한 효과를 측정한다. 같은 고정 목표 Full-FEA 표본과 같은 시험 집합을 사용한다.
5. **B3 MS 자계 사전학습·MGN 잔차/전이학습.** 필드 개선이 AC 손실·제약 판정 개선으로 이어지는지 평가한다. 국부 B 오차만으로 Full-FEA 손실 정확도를 주장하지 않는다.

현재 20형상 자료는 beta=36도, 전류 2수준, 속도 3수준이다. 기존 JEET의 전류–위상 표면을 그대로 재현하기에 축이 부족하다. 해당 데이터에서의 R3/RBF 개발 CV와 위 JEET 성능을 한 순위표로 합치지 않는다. 실제 다중 기준 형상 비교는 새로운 공통 case matrix와 동일한 Full-FEA 예산이 필요하다.

20형상 비교의 MC 비율 보정 모델은 추론 시 제외 형상의 Hybrid 값을 요구하는 Hybrid/MS-assisted 모델이다. 직접 log-loss RBF만 기하·OP 입력으로 손실을 예측한다. Full-FEA 학습 예산이 같아도 저충실도 추론 입력 생성 비용은 같지 않다. 같은 형상의 Full-FEA label을 제외한 것과 새 형상에서 모든 solver 실행을 생략한 것은 다른 조건이다.
