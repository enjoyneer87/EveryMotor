# Astra xHigh · E1과 최근 모델의 성능 차이 판정

2026-10-28 KST. 사용자 요청에 따라 gpt-6-astra / xhigh로 수행한 읽기 전용 판정이다. 본문은 반환된 과학 판정문이며 파일 링크만 공유 가능한 상대 경로로 바꿨다. 실행 권한이나 새 학습 결과를 의미하지 않는다.

**최근 모델이 E1보다 퇴보했다고 단정할 수는 없습니다.** 비교한 지표와 평가집단이 다르고, 최근 모델은 E1의 큰 모델·물리 prior·공극 중심 손실을 이어받지 않은 별도 경량 모델입니다. 다만 이번에 확인된 **그래프 연결 단절과 자계 출력의 제한된 정보 전달 범위**는 후속 실험에서 우선 다룰 근거가 됩니다.

| 항목 | E1 | 최근 A0/A1 |
|---|---|---|
| 평가집단 | legacy6 | innerdev32, E1의 oldTRAIN에 노출 |
| 전체 B크기 오차 | 11.0967% | all45 A0: 13.504/13.290%, A1: 12.531/12.517% |
| 전체 B벡터 오차 | 위 숫자와 다른 지표 | A0: 20.379/20.160%, A1: 19.582/19.331% |
| 공극·토크 | 4.9563% / 3.2146% | 공극 전용·토크 미평가 |
| 구조 | h256/p15, 약 9.29M | width32/depth3, 자계 경로 30,594개 파라미터 |
| 학습 구성 | linear prior, 공극 가중5, spectral30 | prior 없이 전체 면적가중 B벡터 MSE |

E1도 고정 legacy6의 **토크 <3% 관문은 통과하지 못했습니다.** 전체 자계가 5% 이하였던 것도 아닙니다. [E1 원 판정](../../../.github/plans/methodology_review_20260720.md#L2941), [L12 결과](../phase2_multigeometry_turns_20261027/master_plan_artifacts/L12_PHASE45_REPORT_KO.md#L17)

**확인된 차이와 관찰은 다음과 같습니다.**

1. **B크기와 B벡터의 혼용이 격차를 크게 보이게 합니다.** A0 seed17의 같은 all45 예측은 B벡터 20.379%, B크기 13.504%입니다. 같은 분모에서 오차 제곱을 분해하면 약 56%가 크기 차이만으로는 포착되지 않는 방향 관련 항입니다. 이것은 방향 오차의 존재를 보여주지만 원인을 특정하지는 않습니다. 기존 E1은 요소 수 기준으로 집계하며 최근 평가는 요소 면적으로 가중하므로, B크기끼리도 아직 직접 비교할 수 없습니다. [기존 metric](../../../eval/metrics.py#L74), [최근 metric](../phase2_multigeometry_turns_20261027/evaluate_field_l12.py#L63)

2. **최근 그래프의 rotor–stator 메시지 경로 단절은 표본에서 확인됐습니다.** 전달된 topology audit를 직접 읽었습니다. train 6조건×3시각, **18/18 그래프가 두 component로 분리**되어 rotor/magnet에서 stator로 가는 경로가 없습니다. 현재 reader가 a2를 제거한 뒤 인접 관계를 만들기 때문과 일치합니다. E1은 해당 band를 손실에서 제외하면서 메시지 연결은 유지합니다. 다만 전체 데이터 전수 결과는 아니며, 공통 design/OP 조건은 양쪽에 전달되므로 “전자기 상호영향이 전혀 없다”는 표현은 부정확합니다. [감사 결과](GRAPH_TOPOLOGY_AUDIT.json#L1), [현재 graph 구성](../phase2_multigeometry_turns_20261027/native_element_graph.py#L55), [E1 연결 유지](../../../train_doe_curl_mgn.py#L272)

3. **현재 전역 pooling은 자계 출력으로 돌아가지 않습니다.** 자계는 3회 국소 메시지 전달 후 `self.field(h)`로 계산됩니다. pooling은 별도의 shared/alignment 경로에만 들어가고, 실제 학습은 Motor-CAD `fields`에만 손실을 겁니다. 따라서 파일명이 dual-solver여도 이번 결과를 다중 솔버·AC 공동학습 성과로 볼 수 없습니다. 총 70,182개 중 자계 경로는 30,594개입니다. E1의 기록상 약 9.29M과 비교하면 약 300배 규모 차이지만, **그 차이가 정확도에 기여한 양은 미측정**입니다. [모델 경로](../phase2_multigeometry_turns_20261027/dual_solver_mgn.py#L42), [실제 학습 손실](../phase2_multigeometry_turns_20261027/train_field_l12.py#L97)

4. **E1에 있던 전기각 인코딩이 A0/A1에는 빠져 있습니다.** E1의 `rotor_angle_features`는 45° sector에서 `sin/cos(4θm)`입니다. A0/A1은 `sin/cos(θm)`이고, 실행 중인 A2가 이를 전기각으로 바꿉니다. E1의 실제 recipe는 `target=B`이며 nodal B를 요소 평균합니다. `curl`이라는 파일명 때문에 A→curl 모델로 해석하면 안 됩니다. 또한 E1 recipe는 rotor wrapping과 anti-periodic 추가 edge를 껐으므로, 그 두 기능을 E1 우세의 이유로 들 수도 없습니다. [전기각 정의](../../../phase1_static/sector_symmetry.py#L114), [A2 변환](../phase2_multigeometry_turns_20261027/train_field_l12.py#L22)

5. **학습 목적과 예산도 같지 않습니다.** E1은 정규화한 B 손실에 공극 가중5와 공극 고조파 손실30을 더합니다. 최근 모델은 별도 공극 강조 없이 물리 단위 B의 면적가중 MSE를 최소화합니다. E1의 공극 성과가 최근 전체 자계 학습에서 자동으로 유지될 이유는 없습니다. E1은 450조건×45시각, 최근은 328조건이며, L12는 88,565 update로 고정됐습니다. 특히 A1의 `epochs_completed=30`은 **A0 기준 환산값이고 실제 데이터 순회는 6회**입니다. [E1 손실](../../../train_doe_curl_mgn.py#L893)

**L12 판정은 `NO_IMPROVEMENT_CLAIM`을 유지합니다.** 두 seed 평균 전체 B벡터는 0.813pp 낮아졌지만, seen9는 1.544pp 악화했습니다. 이는 사전등록한 개선폭 1.0pp와 seen9 비악화 0.5pp 조건을 충족하지 못합니다. 끝부분 위상의 개선은 확인되지만, “위상 희석이 원인으로 확정됐다”는 해석은 한 단계 강합니다. 표본 노출 횟수 변화는 확인됐고, 정확도 변화의 단독 기여는 아직 분리되지 않았습니다.

남은 가설은 **연결 단절·짧은 수용범위, 작은 용량, prior 부재, 손실 배분, 입력 정규화, 고위상각·포화 조건**입니다. 각각 개연성은 있지만 기여율은 아직 모릅니다. A2의 stator 주기 감사도 인코딩 선택을 지지하는 근거이지, 저장되지 않은 step45와 step0의 전체 이동장·과도상태가 동일하다는 증명은 아닙니다.

**다음 순서는 아래가 가장 경제적입니다.**

1. **진행 중인 A2를 그대로 인계받아 기존 계약으로 판정합니다.** 중복 실행이나 중간 설정 변경 없이 세 seed와 대조군을 모두 회수합니다.
2. **추가 학습 전에 현재 checkpoint들을 공통 평가합니다.** 기존 dev32만 사용하고 예약 형상·old val/test는 열지 않습니다. 동일 native element ID와 공통 mask에서 면적가중/기존 비가중 B크기·벡터, **stationary a1 공극**, 구리, 동일 Arkkio 토크 연산자를 함께 보고합니다. 현재의 `air` 범주는 공극 전용 지표가 아닙니다. 예측 배열이 없으면 소유 작업 종료 후 모델별 동결 추론 한 번으로 수집할 수 있습니다.
3. **그다음 단일축은 자계 경로의 전역 정보 전달을 우선합니다.** 고정된 각도 인코딩·width/depth·손실·update 예산에서 전역 요약을 자계 head에 되돌리는 유무를 비교하고, 가능하면 같은 파라미터 수의 대조군을 둡니다. 잘못된 a2 요소를 손실에 되넣거나 임의 최근접 연결로 단절을 메우지는 않습니다.
4. 공극 오차를 실제 측정한 뒤 **공극 손실 가중**, 그다음 **용량**, 마지막으로 **admission을 통과한 prior/E1 전이**를 각각 분리합니다. 현재 E1 prior binding·예약 donor 제외·normalizer 호환성은 여전히 UNKNOWN이므로 즉시 가중치를 불러오는 순서는 적절하지 않습니다.
