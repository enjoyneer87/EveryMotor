# MotorAI R3 원천검증 판정

새 주기·공극 연결 실험은 HOLD_NOT_RUN입니다. 기존 학습 결과의 그림은 저장된 3시드 수치를 재표현합니다.

`python -B VerifyReport.py`는 공개 파일 목록·해시·저장 수치의 평균/범위와 HTML 링크를 검사합니다. 원본 비공개 자료, 물리 경계조건, 독립시험 정확도를 검증하지 않습니다.

`python -B RenderReport.py`는 matplotlib가 있는 환경에서 기존 그림을 재생성합니다. 환경별 PNG bytes 차이가 생길 수 있으며 원본 패키지를 검증하려면 변경 전 복사본에서 실행하십시오. 새 모델이나 솔버를 실행하지 않습니다.

원본 모델·CHM·벤더 도움말 원문·비공개 경로·weights는 포함하지 않습니다. summary의 근거 해시는 로컬 보존 증거의 식별자이며 공개 검증기가 원본을 다시 취득했다는 뜻이 아닙니다.
